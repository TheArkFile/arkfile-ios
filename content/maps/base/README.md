# ArkFile Offline Base Map

Release builds should place the generated global PMTiles base map artifacts in this folder before generating the Xcode project:

- `global.pmtiles`
- `manifest.json`
- `assets/fonts/...`
- `assets/sprites/v4/light.json`
- `assets/sprites/v4/light.png`

These files are generated by the desktop map-pack workflow and are intentionally ignored by Git because they are release/content artifacts.
